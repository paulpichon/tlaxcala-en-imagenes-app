**Descripción:** Obtiene posteos **públicos** de otros usuarios (excluye los del autenticado), paginados y ordenados por `fecha_creacion` desc. Enriquecidos con `isFollowing`, `isFavorito`, `likesCount`, `hasLiked`.

### Middlewares (en orden)
1. `lecturaLimiter`
2. `verificarTokenSesion`

## POST /api/posteos

**Descripción:** Crea un posteo (imagen obligatoria). Sube a Cloudinary y persiste.
**Archivo de ruta:** `routes/posteos.js:65`
**Controlador:** `controllers/posteos.js` — `posteosPost` (línea 230)

### Autenticación y permisos
- Requiere token: **Sí** (accessToken en cookie)
- Middleware de auth: `verificarTokenSesion`

### Rate limiting
- `posteoLimiter`: 20 req / 15 min → `POSTEO_BLOCKED`

### Middlewares (en orden)
1. `posteoLimiter`
2. `verificarTokenSesion`
3. `upload.single('img')` — Multer 8 MB, jpg/jpeg/png/webp
4. `validarCampoImg`
5. `validarImagenesMulter`
6. `validarTexto` (regex sobre `texto`)
7. `check('posteo_publico', ...).optional().isBoolean()`
8. `check('lat', ...).optional().isFloat()`
9. `check('lng', ...).optional().isFloat()`
10. `validarCampos`

### Parámetros de entrada
| Ubicación | Campo | Tipo | Requerido | Validación exacta |
|---|---|---|---|---|
| multipart | `img` | File | Sí | jpg/jpeg/png/webp, máx 8 MB |
| body | `texto` | string | No | regex `^[a-zA-Z0-9áéíóúÁÉÍÓÚñÑ.,!?¡¿()\s-]*$` (opcional) |
| body | `posteo_publico` | boolean | No | `optional().isBoolean()` |
| body | `municipio` | string | No | (sin validación explícita; se guarda como ObjectId) |
| body | `ciudad` / `estado` / `pais` | string | No | (sin validación) |
| body | `lat` | number | No | `optional().isFloat()` |
| body | `lng` | number | No | `optional().isFloat()` |

### Ejemplo de request
- `multipart/form-data`: `img` (archivo) + campos de texto opcionales.

### Ejemplo de response — éxito
- Código de estado: `201`

```json
{ "success": true, "msg": "Posteo creado correctamente", "data": { "posteo": { "_id": "...", "_idUsuario": "...", "public_id": "...", "secure_url": "...", "texto": "...", "posteo_publico": true, "ubicacion": {...}, "fecha_creacion": "..." } } }
```

### Códigos de error posibles
| Status | code | title | detail | Dónde se lanza |
|--------|------|-------|--------|----------------|
| 401 | `UNAUTHORIZED` | Authentication Required | Token inválido o ausente | `verificarTokenSesion` |
| 404 | `NOT_FOUND` | Resource Not Found | `No hay ninguna imagen para subir` | `middlewares/validar-imagen-posteo.js:19` |
| 400 | `BAD_REQUEST` | Bad Request | `La imagen excede el tamaño máximo permitido (8 MB)` | `middlewares/validar-imagen-posteo.js:27` |
| 422 | `VALIDATION_FAILED` | Validation Failed | `El campo de texto contiene caracteres no permitidos` | `middlewares/validar-texto.js:30` |
| 422 | `VALIDATION_FAILED` | Validation Failed | `El campo posteo_publico debe ser de tipo Boolean` / lat/lng | express-validator |
| 429 | `POSTEO_BLOCKED` | Rate Limit Exceeded | `Demasiadas publicaciones...` | rate-limiter |
| 500 | `INTERNAL_ERROR` | Internal Server Error | `Error interno al procesar la publicación` | `controllers/posteos.js:316` |

### Notas para el Frontend
- La imagen es **obligatoria** (`validarCampoImg`). `texto` opcional (si no llega, `""`).
- **⚠️ Inconsistencia:** `check('posteo_publico').isBoolean()` rechaza string `'true'`, pero el controlador sí lo acepta (`posteo_publico === 'true' || true`). Si el frontend envía `posteo_publico` como string (FormData), puede recibir `422`.
- **Ubicación:** si hay `municipio` o `lat/lng`, se crea `ubicacion` GeoJSON `[lng, lat]`. `esExacta` es `true` solo con lat y lng.
- **Compensación:** si falla el `save()` tras subir a Cloudinary, se destruye la imagen huérfana.
