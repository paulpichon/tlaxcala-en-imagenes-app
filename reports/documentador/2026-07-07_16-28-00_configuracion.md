## 5. Configuración de Next.js (`next.config.ts`)

```typescript
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  images: {
    remotePatterns: [
      {
        protocol: 'https',
        hostname: 'res.cloudinary.com',
        pathname: '/dy9prn3ue/**',
      },
    ],
  },
};

export default nextConfig;
```

- **remotePatterns:** Solo permite imágenes desde `res.cloudinary.com` en el path `/dy9prn3ue/**`.
- No hay configuración de `output`, `basePath`, `assetPrefix`, u otras opciones avanzadas.

## 13. Problemas Conocidos y Limitaciones

1. **Sin linter ni formateador:** No hay ESLint, Prettier ni herramientas similares configuradas.
2. **Sin pruebas:** No existe infraestructura de testing (sin Jest, Cypress, Playwright, etc.).
3. **Sin tipo de comprobación automática:** No hay script de `typecheck` en `package.json`.
4. **Anuncios hardcodeados:** La publicidad está definida estáticamente en `PublicidadContext.tsx` con URLs fijas.
5. **FavoritoContext no está en el layout raíz:** Se provee por separado en cada layout de sección, lo que puede causar que no esté disponible en todos los componentes.
6. **Sin manejo de Service Worker:** Aunque `usePushNotifications` intenta registrar `/sw.js`, no se encontró un archivo Service Worker en `public/`.
7. **Mezcla de estilos:** Algunos componentes usan Bootstrap directamente, otros usan CSS Modules, y algunos mezclan ambos enfoques.
