## 3. Resumen Técnico Rápido

- **Framework:** Next.js 16.2.6 (App Router)
- **React:** 19.2.6
- **TypeScript:** 6.0.3
- **Estado global:** Context API (6 contextos)
- **Estilos:** Bootstrap 5.3 + CSS Modules
- **Formularios:** react-hook-form + Zod 4
- **Imágenes:** Cloudinary con presets personalizados
- **Autenticación:** JWT basado en cookies con refresh automático
- **Paquetería:** pnpm
- **Idioma UI:** Español (es_MX)
