## 1. Hooks Personalizados (`src/app/hooks/`)

### useInfinitePosts
- **Ubicación:** `src/app/hooks/useInfinitePosts.ts`
- **Descripción:** Hook para scroll infinito de publicaciones. Usa Intersection Observer para detectar cuándo cargar más posts.
- **Parámetros:**
  | Parámetro | Tipo | Descripción |
  |-----------|------|-------------|
  | `initialUrl` | `string` | URL inicial para obtener posts |
- **Retorno:**
  | Propiedad | Tipo | Descripción |
  |-----------|------|-------------|
  | `posts` | `Posteo[]` | Lista acumulada de posts |
  | `loading` | `boolean` | Estado de carga |
  | `observerRef` | `RefObject<HTMLDivElement>` | Ref para el elemento observado |
  | `finished` | `boolean` | Indica si no hay más posts |
  | `updateFollowState` | `(userId, newState) => void` | Actualiza estado isFollowing en posts |
  | `updateFavoritoState` | `(postId, newState) => void` | Actualiza estado isFavorito en posts |
- **Dependencias:** AuthContext (fetchWithAuth)
- **Efectos:** Configura IntersectionObserver con margen de 200px y threshold 0.1. Limpia el observer al desmontar.

### useComentarios
- **Ubicación:** `src/app/hooks/useComentarios.ts`
- **Descripción:** Hook para manejar comentarios de una publicación. Proporciona carga, creación, eliminación y paginación.
- **Parámetros:**
  | Parámetro | Tipo | Descripción |
  |-----------|------|-------------|
  | `postId` | `string` | ID del posteo |
- **Retorno:**
  | Propiedad | Tipo | Descripción |
  |-----------|------|-------------|
  | `comentarios` | `Comentario[]` | Lista de comentarios |
  | `total` | `number` | Total de comentarios |
  | `loadingList` | `boolean` | Carga inicial |
  | `loadingMore` | `boolean` | Carga de más comentarios |
  | `hasMore` | `boolean` | Indica si hay más páginas |
  | `fetchComentarios` | `() => Promise<void>` | Carga inicial de comentarios |
  | `fetchTotal` | `() => Promise<void>` | Obtiene el total de comentarios |
  | `cargarMasComentarios` | `() => Promise<void>` | Carga siguiente página |
  | `agregarComentario` | `(texto: string) => Promise<boolean>` | Crea un comentario (optimista) |
  | `eliminarComentario` | `(commentId: string) => Promise<boolean>` | Elimina un comentario |
- **Dependencias:** AuthContext (fetchWithAuth, user)
- **Efectos:** Al montar, obtiene el total de comentarios.
- **Notas:** La creación de comentarios es optimista: se agrega temporalmente con ID `temp_` y se reemplaza con el ID real al recibir respuesta del servidor. Si falla, se revierte.

### useCrearPosteo
- **Ubicación:** `src/app/hooks/useCrearPosteo.ts`
- **Descripción:** Hook que maneja todo el estado y la lógica para crear una nueva publicación. Incluye validación Zod de imagen y texto, detección de móvil, y gestión de ubicación.
- **Parámetros:**
  | Parámetro | Tipo | Descripción |
  |-----------|------|-------------|
  | `onPostCreated` | `(newPost?: Posteo) => void` | Callback al crear posteo |
  | `onSuccess` | `() => void` | Callback al completar con éxito |
- **Retorno:**
  | Propiedad | Tipo | Descripción |
  |-----------|------|-------------|
  | `file` | `File \| null` | Archivo de imagen seleccionado |
  | `preview` | `string \| null` | URL de previsualización |
  | `texto` | `string` | Texto de descripción |
  | `posteoPublico` | `boolean` | Privacidad del posteo |
  | `loading` | `boolean` | Estado de subida |
  | `showConfirmDiscard` | `boolean` | Mostrar confirmación al descartar |
  | `errors` | `string[]` | Errores de validación |
  | `isMobile` | `boolean` | Detecta si es dispositivo móvil |
  | `processFile` | `(f: File \| null) => void` | Valida y procesa archivo |
  | `handleSubmit` | `() => Promise<void>` | Envía el formulario |
  | `resetForm` | `() => void` | Reinicia el formulario |
  | `obtenerUbicacion` | `() => Promise<...>` | Obtiene ubicación por GPS |
  | `municipioId, ciudad, estado, pais, lat, lng` | varios | Datos de ubicación |
  | `loadingUbicacion` | `boolean` | Estado de carga de ubicación |
  | `ubicacionError` | `string \| null` | Error de ubicación |
- **Dependencias:** AuthContext (fetchWithAuth), useObtenerUbicacion, Zod (posteoSchema, posteoBaseSchema)
- **Efectos:** Detecta móvil al montar y al cambiar tamaño de ventana. Valida la imagen con Zod inmediatamente al seleccionarla.
- **Límites:** Texto máx. 200 caracteres. Imagen máx. 5 MB. Formatos: jpeg, jpg, png, webp.

### useObtenerUbicacion
- **Ubicación:** `src/app/hooks/useObtenerUbicacion.ts`
- **Descripción:** Hook para obtener la ubicación del usuario usando la API de geolocalización del navegador y convertir coordenadas a municipio mediante el backend.
- **Parámetros:** Ninguno
- **Retorno:**
  | Propiedad | Tipo | Descripción |
  |-----------|------|-------------|
  | `lat, lng` | `number \| null` | Coordenadas GPS |
  | `obtenerUbicacion` | `() => Promise<...>` | Obtiene ubicación |
  | `loadingUbicacion` | `boolean` | Estado de carga |
  | `ubicacionError` | `string \| null` | Mensaje de error |
  | `municipioId, ciudad, estado, pais` | `string \| null` | Datos de ubicación |
  | `setMunicipioId, setCiudad, setEstado, setPais, setLat, setLng` | Setters | Permiten modificar ubicación manualmente |
- **Dependencias:** AuthContext (fetchWithAuth)
- **Flujo:**
  1. Obtiene coordenadas del navegador (`navigator.geolocation.getCurrentPosition`)
  2. Envía coordenadas al backend: `POST /api/ubicacion/reverse`
  3. El backend devuelve el municipio correspondiente
  4. Establece `pais` como "México" por defecto

### usePushNotifications
- **Ubicación:** `src/app/hooks/usePushNotifications.ts`
- **Descripción:** Hook para gestionar notificaciones push en el navegador. Permite activar/desactivar notificaciones usando Service Workers y la Push API.
- **Parámetros:** Ninguno
- **Retorno:**
  | Propiedad | Tipo | Descripción |
  |-----------|------|-------------|
  | `estado` | `"idle" \| "pending" \| "enabled" \| "disabled" \| "error"` | Estado actual |
  | `activarNotificaciones` | `() => Promise<void>` | Activa notificaciones push |
  | `desactivarNotificaciones` | `() => Promise<void>` | Desactiva notificaciones push |
- **Dependencias:** AuthContext (user, fetchWithAuth)
- **Flujo de activación:**
  1. Registra Service Worker (`/sw.js`)
  2. Solicita permiso `Notification.requestPermission()`
  3. Obtiene clave VAPID pública del backend
  4. Crea suscripción push con `registration.pushManager.subscribe()`
  5. Envía suscripción al backend

## 2. Utilidades de Biblioteca (`src/lib/`)

### getCloudinaryUrl (`src/lib/cloudinary/getCloudinaryUrl.ts`)
- **Descripción:** Genera URLs transformadas de Cloudinary según presets predefinidos o configuración personalizada.
- **Parámetros:**
  | Parámetro | Tipo | Requerido | Default | Descripción |
  |-----------|------|-----------|---------|-------------|
  | `publicId` | `string` | Sí | — | ID público de la imagen en Cloudinary |
  | `preset` | `CloudinaryPreset` | No | `"feed"` | Preset de transformación |
  | `options` | `CloudinaryCustomOptions` | No | `{}` | Opciones custom (si preset es "custom") |
- **Retorno:** `string` — URL transformada de Cloudinary
- **Características:**
  - Limpia extensiones de archivo del publicId
  - Codifica segmentos del path
  - Presets predefinidos: feed, detalle, perfil, grid, mini
  - Omite `f_auto` para evitar bugs de imágenes rotas
  - Soporta opciones custom: width, height, crop, gravity, background, quality, format, useAutoTransforms

---

### obtenerImagenPerfilUsuario (`src/lib/cloudinary/obtenerImagenPerfilUsuario.ts`)
- **Descripción:** Determina la URL de la imagen de perfil de un usuario. Si tiene imagen personalizada, devuelve la URL optimizada de Cloudinary; si no, devuelve la imagen por defecto.
- **Parámetros:**
  | Parámetro | Tipo | Descripción |
  |-----------|------|-------------|
  | `user` | `UsuarioLogueado` | Datos del usuario |
  | `preset` | `CloudinaryPreset` | Preset de transformación |
- **Retorno:** `string` — URL de la imagen de perfil
- **Dependencias:** getCloudinaryUrl, `NEXT_PUBLIC_IMAGEN_PERFIL_DEFAULT`

### validaciones (`src/lib/validaciones.ts`)
- **Descripción:** Esquemas de validación Zod para formularios.
- **Esquemas exportados:**

| Esquema | Descripción |
|---------|-------------|
| `usuarioSchema` | Validación de registro: nombre (requerido), apellido (requerido), correo (email válido), password (8+ caracteres, mayúscula, minúscula, número, especial) |
| `correoSchema` | Solo validación de correo (usado en recuperación de contraseña) |
| `passwordSchema` | Solo validación de contraseña |
| `resetPasswordSchema` | Validación de contraseña + confirmación (deben coincidir) |
| `posteoBaseSchema` | Validación de posteo: texto (max 200, caracteres permitidos), file (max 5MB, tipos jpeg/jpg/png/webp), posteo_publico |
| `posteoSchema` | Extiende baseSchema: requiere texto o imagen |
| `editarPosteoSchema` | Validación de edición de posteo: texto (max 200, spam regex) |
| `schemaAyudaSoporte` | Validación de formulario de ayuda: tipo_problema (enum), descripción (10-1000 caracteres) |
| `comentarioSchema` | Validación de comentarios: texto (1-250 caracteres, spam regex) |
| `imageFileSchema` | Validación de imagen de perfil: tipos jpeg/jpg/png/webp |
